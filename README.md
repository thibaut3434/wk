# WK 2026 Website

Een simpele statische website voor het WK 2026.

## Openen op deze pc

Dubbelklik op `index.html`.

## Lokaal draaien

```powershell
python -m http.server 8080
```

Open daarna:

```text
http://127.0.0.1:8080
```

## Online zetten

Deze site bestaat uit gewone statische bestanden:

- `index.html`
- `styles.css`
- `app.js`

Je kan hem daardoor makkelijk publiceren via GitHub Pages, Netlify of Vercel.
